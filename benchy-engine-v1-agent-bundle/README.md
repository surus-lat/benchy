# Benchy Engine 1.0 Agent Bundle

Read in this order:

1. `technical-paper-v10.md` — semantic design + normative engineering appendix.
2. `benchy-engine-agent-handoff-v1.md` — architecture and implementation responsibilities.
3. `benchy-engine-spec-v1.md` — compact normative conformance rules.
4. `benchy-engine-build-plan-v1.md` — implementation phases and test matrix.
5. `surus-ontology-v1.0.yaml` — shared ontology registry example.
6. `example-benchmark-v1.0.yaml` — canonical benchmark definition.
7. `example-ir-v1.0.json` — representative compiled IR.
8. `example-result-v1.0.json` — representative engine result.
9. `example-dataset-v1.0.jsonl` — dataset encoding example.

The handoff and spec are intended to be sufficient for an implementation agent to begin building without consulting prior conversations.
